| BUG-01 | **UAT 19 & 20:** Cross-Project Isolation | AE should get 403 when trying to view unassigned projects. | AE successfully fetched unassigned project (200 OK). | **CRITICAL** | Spatie's `Gate::before` interceptor was returning `true` because AE holds the `'view'` permission globally, bypassing `ProjectPolicy::view`. | Disable Spatie's global interceptor via `config/permission.php` (`register_permission_check_method => false`). | FIXED |

| BUG-03 | **UAT 12 & 14:** File Version Approvals | CD requesting revision/approval should succeed (201 Created). | CD receives 403 Forbidden. | **MEDIUM** | Polymorphic `ApprovalController` enforces `$this->authorize('update', $model)` but `FileVersionPolicy` was missing. | Create `FileVersionPolicy` mapping `update` authorization to the parent project's CD/AE/SMS. | FIXED |
| BUG-04 | **UAT 09:** Create Task | Task creation succeeds (201 Created). | Validation Error (422) for missing `task_no`. | **LOW** | Simulation payload omitted the `task_no` required string parameter. | Update UAT Simulation test payload to include `'task_no' => 'TSK-001'`. | FIXED |

| BUG-07 | **UAT 18:** Admin Dashboard | Dashboard returns `total_projects` metric. | Failed asserting array has key `projects`. | **LOW** | Test asserted `projects` key instead of the API's actual `total_projects` response. | Fix test assertion. | FIXED |
