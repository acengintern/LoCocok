66. Kesimpulan Kebutuhan Utama
1. Gambaran Umum Sistem
LOCO TRACK adalah sistem internal perusahaan untuk mengelola seluruh aktivitas produksi konten dan project secara terintegrasi mulai dari Client → Brief → Content Planning → Script/Ideation → Assignment → Production → Internal Review → Creative Director Review → Client Review → Revision → Approval → Publish → Done.
Sistem tidak hanya menyimpan project, tetapi juga harus mampu:
mengelola client/project;
mengelola PIC;
menerima dan menyimpan brief;
membuat content plan;
membuat task;
melakukan assignment Designer/Editor;
mengatur deadline;
memonitor workload masing-masing anggota;
melakukan upload file;
melakukan QC;
melakukan approval;
melakukan revisi;
melakukan publish;
memonitor project;
memonitor timeline;
menghitung progress;
memonitor project overdue/overtime;
memonitor output target vs realisasi;
membuat daily/weekly/monthly report;
membuat laporan project, output, timeline, workload, client, dan finansial;
menyimpan activity log.
Pada brief, halaman inti yang disebutkan adalah Dashboard, Project List, Project Detail, Activity Log, dan User Management, dengan widget project, deadlines, overdue, workload, task, dan approvals.
2. Role Pengguna

Fungsi Utama

Mengelola pengguna, role, permission, master data, dan konfigurasi.
Creative Director (CD)
QC, approval, monitoring project.
Account Executive (AE)
Monitoring project, deadline, distribusi pekerjaan, dan workflow.
Social Media Specialist (SMS)
Client communication, brief, content plan, assignment, preview, publish.
Graphic Designer (DG)
Produksi desain.
Video Editor / DAV
Produksi/editing video.
KOL
Pekerjaan yang berkaitan dengan KOL sesuai task yang ditugaskan.
Production Assistant (PA)
Pekerjaan operasional/production assistant sesuai task.
Catatan: KOL dan PA muncul pada workbook Production Team, sedangkan User Management pada brief menunjukkan kebutuhan administrator. Hak akses final KOL/PA dan akses finansial perlu dikonfirmasi sebelum implementasi.

64. Notifikasi
Assignment: Anda mendapatkan task baru.
Deadline: Task Anda memiliki deadline hari ini.
Overdue: Task telah melewati deadline.
QC: Task menunggu review Creative Director.
Revision: Task mendapatkan revisi.
Client Review: Project siap dikirim ke client.
Approval: Project telah disetujui.
Publish: Content siap dipublish.
65. Business Rules Penting
Task wajib memiliki PIC.
Task production/revision tertentu wajib memiliki deadline.
Assignment harus memunculkan warning jika beban PIC berpotensi bentrok.
Designer/Editor tidak dapat melakukan approval atas pekerjaannya sendiri.
Client Preview harus melewati QC.
Publish dilakukan oleh SMS sesuai permission sumber.
Revision membuat history dan tidak menghapus versi sebelumnya.
Semua perubahan dicatat dalam Activity Log.
Project overdue terdeteksi otomatis.
Output dihitung otomatis.
Sisa = Target - Realisasi
Progress = Realisasi / Target × 100%

SUMBER DAN DASAR ANALISIS
TRACKER BRIEF(1).pdf — digunakan sebagai dasar role, permission, halaman inti, project workflow, project status, dashboard, dan approval workflow.
LOCO TRACK SMS - MONDAY CHALLENGE(1).pdf — digunakan sebagai dasar pola daily workload, pembagian pekerjaan berdasarkan tanggal/PIC/project, dan contoh aktivitas harian.
